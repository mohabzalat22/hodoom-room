== Frequently Asked Questions ==

= What is Merchant and what does it do? =

Merchant is an all-in-one WooCommerce plugin that adds sales, conversion, and average-order-value features through 40+ modules you enable individually. It covers product labels, quick view, buy now, pre-orders, frequently bought together, bulk discounts, variation swatches, wishlists, checkout layouts, and more, replacing what would otherwise be 20+ separate plugins.

= Is Merchant free? =

Yes. The free version includes 16 modules and is available on WordPress.org at no cost. Merchant Pro adds 30+ more modules, built-in analytics, campaign scheduling, and email support, starting at $79/year.

= Can Merchant replace multiple WooCommerce plugins? =

Yes. Merchant is designed to replace single-purpose plugins for bundles, discounts, swatches, wishlists, quick view, checkout layouts, and more. You manage every feature from one plugin, with one license to renew and one plugin to update instead of a dozen.

= Will 40+ modules slow down my WooCommerce store? =

No. Merchant is modular and loads only the modules you turn on, so disabled features add no front-end weight. Site speed depends on plugin quality rather than count, and consolidating several plugins into one well-coded plugin usually reduces total scripts and database queries. Merchant is built to pass Google's Core Web Vitals.

= Is Merchant a good alternative to YITH, WPClever, or Barn2? =

Merchant is a single-plugin alternative to running several plugins from YITH, WPClever, Flycart, or Barn2. Those tools each add one capability; Merchant combines the equivalents under one settings interface and adds two things single-purpose plugins usually lack: built-in analytics on each module's impressions, conversions, and revenue, and campaign management with scheduling, display conditions, and user-role targeting on the modules that support it.

= Does Merchant include analytics? =

Yes. Merchant Pro includes built-in analytics that track each module's impressions, conversions, and revenue, so you can see which modules drive sales rather than guessing. Refunded orders are removed from the data automatically.

= Can I schedule sales and campaigns with Merchant? =

Yes. Modules such as Pre-Orders, and Countdown Timer run as scheduled campaigns with start and end dates, display conditions, and targeting by user role, so you can plan promotions in advance.

= Does Merchant work with any theme and the block checkout? =

Yes. Merchant works with any well-developed WooCommerce theme and declares support for the WooCommerce cart and checkout blocks and for High-Performance Order Storage (HPOS). If a module conflicts with your theme, the support team can help.

= Do I need WooCommerce or coding skills to use Merchant? =

Most Merchant modules require WooCommerce to be installed, and none require coding. You enable and configure each module from the dashboard without editing theme files or writing code.

= Can I use Merchant on client sites? =

Yes. You can use Merchant on client websites, including under the Agency license for managing many stores.
